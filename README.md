# Paratag

A lightweight and elegant **Obsidian vault template** that combines a **minimal tagging system** with **Tiago Forte’s PARA method**. Old

This approach keeps your vault simple, flexible, and future-proof:  

- Tags provide fast cross-linking  
- PARA ensures a clear structure for projects, areas, resources, and archives  

No heavy plugins. No over-engineering. Just a **practical framework** that works out of the box for both beginners and advanced users.  

---

## Features

- Simple **tagging workflow** integrated with PARA  
- Weekly, monthly, and contact notes via **Quick Add**  
- Works as a **skeleton system** you can adapt and scale  
- Minimalist design with [JetBrains Mono font](https://www.jetbrains.com/lp/mono/)  

---

## Getting Started

1. Clone or download this vault template.  
2. Open the **Command Palette** (`cmd + P` on macOS, `ctrl + P` on Windows).  
3. Use the following quick actions:
   - **New Note** → instantly create a standard note  
   - **Weekly Note** → generate a weekly template  
   - **Monthly Note** → generate a monthly template  
   - **Contact** → create a structured contact entry  

---

## Philosophy

This template is not a rigid system. It is a **scaffold** - a starting point you can reshape to fit your workflow. The combination of **tags** and **PARA** ensures clarity without locking you into a single method.  

One vault. One system. Infinite clarity.
